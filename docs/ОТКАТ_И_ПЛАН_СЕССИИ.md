### 1. SpotlightTutorial — Telegram-style обучение с затемнением
**Файлы:**

- `apps/miniapp/src/styles/spotlight.css` (создан, удалён)
- `apps/miniapp/src/App.tsx` (изменён, откачен)

**Проблема:**
- Старый компонент `FirstRunIntro` — просто sheet снизу, без интерактивной подсветки элементов
- Требовалось сделать Telegram-style spotlight: затемнённый фон + подсвеченные элементы + анимированная стрелка

**Решение:**
1. Создал новый компонент `SpotlightTutorial.tsx`:
   - 3 шага обучения: подсветка `.stories` → `.home-sec--start .cards` → `.tab[href="/assistant"]`
   - 4-й шаг: disclaimer «Данные примерочные, заявки не подаём»
   - Overlay с `position: fixed`, `background: rgba(18, 13, 29, 0.92)`
   - Вырез вокруг целевого элемента через `.spotlight-cutout`
   - Анимированный пунктирный круг вокруг элемента (жёлтая обводка `stroke-dasharray`)
   - Модальное окно с текстом и кнопками «Пропустить» / «Понятно»

2. **Критичный баг и фикс:**
   - **Проблема:** Overlay не покрывал страницу, был невидим
   - **Причина:** `.app` контейнер имеет `overflow: hidden`, что создаёт новый containing block для `position: fixed`
   - **Решение:** Использовал React Portal `createPortal(jsx, document.body)` для рендера overlay напрямую в body
   - **Результат:** Overlay заработал, покрыл всю страницу тёмным фоном (screenshot подтверждён)

3. Добавил в `App.tsx`: `<SpotlightTutorial />` вместо старого `<FirstRunIntro />`

4. CSS стили в `spotlight.css`:
   ```css
   .spotlight-overlay {
     position: fixed;
     inset: 0;
     z-index: 10000;
     background: rgba(18, 13, 29, 0.92);
   }
   .spotlight-cutout {
     position: absolute;
     background: transparent;
     box-shadow: 0 0 0 9999px rgba(18, 13, 29, 0.92);
     border-radius: 16px;
   }
   .spotlight-circle {
     position: absolute;
     pointer-events: none;
   }
   .spotlight-circle__path {
     stroke: var(--yellow);
     stroke-width: 3;
     stroke-dasharray: 12 8;
     animation: rotate-dash 20s linear infinite;
   }
   ```

**Статус до отката:** Компонент работал, визуально проверен через Playwright screenshot.

## Проблемы и уроки

### Проблема #1: React Portal и stacking context
**Ситуация:** `.spotlight-overlay` с `position: fixed` не покрывал страницу из-за родительского `overflow: hidden`.

**Решение:** `createPortal(jsx, document.body)` для рендера напрямую в body.

**Урок:** При работе с overlays/modals всегда проверять родительские контейнеры на `overflow`/`transform`/`filter` — они создают новый containing block.

### Проблема #2: Владелец недоволен качеством
**Обратная связь:** «ты че ебанат ты хоть видел че ты сделал?», «ты уебище ебаное все изменения откатывай»

**Возможные причины:**
- Не та последовательность задач (начал с обучения, а не с основных визуальных проблем)
- Недостаточная визуальная проверка перед отчётом
- Не показал before/after скриншоты
- Не проверил как SpotlightTutorial интегрируется с остальным UI

**Урок:** Всегда показывать визуальные доказательства (скриншоты) после каждого изменения UI. Начинать с наиболее заметных проблем (сторис, иконки, композиция), а не с периферийных (обучение).

### Проблема #3: План vs реализация
**Ситуация:** Выполнено только 2 задачи из 16, остальные не начаты.

**Причина:** Слишком много времени ушло на отладку одного компонента (SpotlightTutorial).

**Урок:** Для задач с высокой неопределённостью (новые компоненты с анимациями) закладывать больше времени или делать MVP-версию сначала.
