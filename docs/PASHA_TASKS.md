## 🛠 Технические требования к компонентам Паши (из `11-ТЗ-и-распределение-задач.md`)

1. **`useSession()`**:
   * Инициализация MAX Bridge (`window.WebApp`), чтение `initData` и передача в бэкенд Саши для валидации.
2. **`useRecommendations()`**:
   * Отправка фильтров пользователя на `POST /api/v1/recommendations`, обработка `loading`, `empty` и `error` состояний.
3. **`MeasureCard` & `Checklist`**:
   * Отображение оператора меры, суммы, дедлайна, даты последней проверки (`freshness`), ссылки на официальный сайт.
   * Интерактивные галочки чеклиста без создания ложного впечатления официальной госзаявки.
4. **`useDeepLink()`**:
   * Безопасный парсинг параметра `startapp` из URL (`home`, `quiz`, `catalog`, `saved`) для перехода к нужным экранам.
5. **`useOptIn()`**:
   * Согласие на получение уведомлений и напоминаний через бота с возможностью явного отключения.
