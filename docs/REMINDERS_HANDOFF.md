# Handoff: напоминания

Это задание на следующую реализацию. Кода отправки здесь нет и в этой задаче его писать нельзя.

## Что уже есть

Глобальное согласие: `GET` и `POST /api/v1/notifications/opt-in`, тело и ответ `{enabled: boolean}`. Пока записи нет, согласие выключено. Сохранение флага ничего не отправляет.

## Когда можно напоминать

Пользователь явно включил глобальное согласие. Без этого сообщения нет: ни о сохранённой мере, ни о сроке, ни с deep link.

После явного включения бот может:

- напомнить о сохранённой мере;
- напомнить о приближении дедлайна;
- прислать deep link `measure_<id>` с ID каталога.

Пока `deadline` равен `null`, напоминание о сроке не создаётся. Срок не выдумывается.

## Правила следующей реализации

- Часовой пояс — `Europe/Moscow`.
- Повтор одного и того же напоминания не должен плодить новые отправки: нужна идемпотентность. Exactly-once не обещать.
- Выключение согласия останавливает будущие напоминания. Сообщение без действующего согласия запрещено.
- Внешняя отправка по-прежнему запрещена без отдельного разрешения владельца.
- PDF в этот handoff не входит.
