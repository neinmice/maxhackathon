## ⚙️ 3. Для Саши (Бэкенд, Бот и Архитектура)

Саша, твоя архитектура сервисов `services/bot` и `services/api` легла в основу интеграции:

1. **MAX WebApp Bridge и Аутентификация**:
   * Все запросы на сохранение мер, прохождение квиза и уведомления передают заголовок `X-Max-Init-Data`.
   * При запуске внутри MAX имя пользователя читается напрямую из `window.WebApp.initDataUnsafe.user.first_name` (в автономном браузере действует фоллбэк на «Анастасия»).

2. **Deep-linking из Бота в Mini App**:
   * В `apps/miniapp/src/App.tsx` реализован перехват параметра запуска `startapp` / `tgWebAppStartParam` / `start_param`:
     * `payload=home` → Главный экран.
     * `payload=quiz` → Мгновенное открытие окна квиза (`QuizModal`).
     * `payload=catalog` → Переход в каталог грантов и мер (`/grants`).
     * `payload=saved` → Переход в личный кабинет к сохранённым мерам (`/profile`).
     * `payload=onboarding` → Открытие шторки подбора мер (`OnboardingSheet`).
     * `payload=measure` → Открытие детальной карточки меры (`MeasureDetailSheet`).

3. **Синхронизация данных с API**:
   * `POST /api/v1/quiz/submit` — отправка ответов квиза версии `v1`, валидация результата, генерация `certificate_id` и подписи HMAC-SHA256. Предусмотрен детерминированный локальный фоллбэк для оффлайн-демонстрации.
   * `POST /api/v1/measures/{id}/save` и `DELETE /api/v1/measures/{id}/save` — добавление/удаление мер из избранного.
   * `POST /api/v1/notifications/opt-in` — сохранение согласия пользователя на напоминания о дедлайнах грантов.

4. **Тесты бэкенда**:
   * Все unit-тесты бота (`services/bot/tests/test_bot.py`) проходят: `3 passed` (проверка `init_data`, дедупликация входящих вебхуков по хэшу, сохранение мер и подпись сертификатов).
   * Все тесты API (`services/api/tests/test_api.py`) проходят: `2 passed`.

## 💻 5. Как запустить и проверить локально

### Запуск фронтенда:
```bash
cd apps/miniapp
npm install
npm run build    # Проверка сборки (0 ошибок, ~470 мс)
npm run preview  # Запуск локального сервера (порт 5173)
```

### Запуск тестов бэкенда:
```bash
# Тесты бота
uv run --with fastapi --with httpx --with "psycopg[binary]" --with pytest pytest services/bot/tests/test_bot.py

# Тесты API
uv run --with fastapi --with httpx --with pytest python -m pytest services/api/tests/test_api.py
```

### Прямые ссылки для проверки в браузере:
* Главная: `http://localhost:5173/`
* Онбординг: `http://localhost:5173/?startapp=onboarding`
* Карточка меры и чеклист: `http://localhost:5173/?startapp=measure`
* Квиз и сертификат: `http://localhost:5173/?startapp=quiz`
* Ассистент: `http://localhost:5173/assistant`
* Гранты: `http://localhost:5173/grants`
* Профиль: `http://localhost:5173/profile`
