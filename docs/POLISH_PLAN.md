Правила:

- Существующий `VKSansDisplay-Regular.woff2` оставить только как вес 400. Один файл не объявлять диапазоном 100–900 — каждый `@font-face` несёт один конкретный вес.

- Убрать `Unbounded` и `Manrope` из приложения и презентации. Известные места: `--display: 'Unbounded', …` в [`apps/miniapp/src/styles.css`](../apps/miniapp/src/styles.css:35), `--font-family: 'Manrope', …` в [`apps/miniapp/src/styles/tokens.css`](../apps/miniapp/src/styles/tokens.css:69), четыре `@font-face` Unbounded и `--display:"Unbounded",…` в [presentation/deck.css](../../../presentation/deck.css:1). Файлы `unbounded-*.woff2` из `presentation/assets/fonts/` удалить после проверки отсутствия ссылок.
- Роли: Expanded Bold — заголовки и крупные цифры; прямой Display Medium/DemiBold — кнопки и подписи; Condensed Bold — бейджи; Text Regular/Medium — основной текст.
