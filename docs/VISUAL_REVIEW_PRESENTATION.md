## 3. Quality Gate — evidence и его границы

Подтверждено артефактами (файловый/текстовый анализ, эта сессия):

- **14 sections/pages** — да (см. §2).
- **16:9** — да: PDF-страницы 1440×810, CSS-кадр и экспорт 1920×1080.
- **Assets/fonts** — на уровне файлов и CSS-объявлений: все 7 подключённых через `@font-face` woff2 присутствуют в `presentation/assets/fonts/`; все 6 ссылок ассетов в HTML (`favicon.svg`, 3 маскота, 2 скриншота) указывают на существующие файлы. Runtime-проверка загрузки в браузере в этой сессии не выполнялась.

Не подтверждено в этой сессии (запрещено заявлять как пройденное):

- **`errors: none` / `overflow: none`** — свежий отчёт экспортёра `node tools/export-pdf.mjs` в этой сессии не получен; свежесть PDF подтверждена только mtime.
- **Visual QA 14-слайдовой версии** — скриншоты `maxhackathon/docs/visual-qa/presentation/slide-01..16.png` датированы 2026-09-29 и описывают прежнюю 16-слайдовую версию; для текущей 14-слайдовой версии постраничный визуальный просмотр не зафиксирован.

Требования к PDF (без изменений): экспорт только повторным запуском `node tools/export-pdf.mjs` из актуального `presentation/index.html`; критерии приёмки — `errors` и `overflow` в отчёте экспортёра `none`, число страниц PDF = числу слайдов; любое изменение содержания/оформления делает PDF устаревшим — переэкспорт обязателен. При недоступности Playwright/Chromium ошибку не маскировать (правила `presentation/AGENTS.md`, §4–5).

## 4. Claim-status правила

Источники: `docs/07-оценка-и-запреты.md`, `presentation/AGENTS.md` §3.

- Каждое утверждение получает статус: `FACT`, `CONFIRMED`, `TEAM DECISION`, `MODEL DATA`, `HYPOTHESIS`, `UNKNOWN`. Гипотеза не превращается в маркетинговый факт.
- Уровень deck — четыре категории статуса: **Факт** (наблюдение + ограничение), **Частичное**, **Roadmap** (план, не достигнутый результат), **Отказано** (явно не делаем).
- Модельные данные маркируются `MODEL DATA`.
- Запрещено вставлять фиктивные адреса, метрики, отзывы, партнёров, статусы интеграции и результаты тестов.

## 6. Открытые blockers

1. **Runtime Quality Gate не прогнан для 14-версии:** нет свежего отчёта `export-pdf.mjs` (`errors`/`overflow` = `none`) и постраничного visual-просмотра текущего deck; PDF свежее исходников по mtime, но гейт не зафиксирован.
2. **Отсутствующие MAX-скриншоты:** в deck нет скриншотов реального MAX-клиента (в HTML используются только 2 скриншота приложения: onboarding-sheet, quiz-certificate).
3. **PDF-in-MAX delivery:** доставка PDF через MAX не настроена и не подтверждена.
4. **honesty-regressions exit 1:** health маскирует недоступность bot (Baseline 2026-09-30, см. `Project_HackathonMAX2026`).
5. **pytest api/bot BLOCKED:** в окружении нет `python3.12` и `.venv`.
6. **CI:** в текущем workflow нет honesty-шага.
7. **`/profile`:** единственный оставшийся раздел фронтенд-полировки.

Закрытый blocker: дельта структуры 16↔14 — устранена реализацией 14-слайдовой версии (см. §1–2).
